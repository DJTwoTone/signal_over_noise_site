SIGNAL OVER NOISE — ICON LIBRARY

64 original reusable SVG icons, organized into eight categories. Each SVG has a transparent background, a 64×64 viewBox, a consistent 2.8 px rounded outline, and a restrained warm-gold detail on selected marks.

PALETTE
Deep navy #132033 · Brand blue #0B2D53 · Mid blue #193B64 · Warm gold #8A641F · Light gold #F2E5C8 · Warm paper #F5F0E8 · Soft white #FAF7F2.

USE
Import individual SVGs into Canva for clean scaling. Start at 20–24 px in compact UI, 32–40 px in cards, and 48–64 px for larger callouts. The circular frame on the core-symbols reference is optional; the reusable source icons have no baked-in background or badge. Keep a clear margin around each mark; pair unfamiliar symbols with a short label. Use one icon to clarify a choice or action, not as decoration. Gold is an accent only, never the sole indicator of meaning. On dark navy, use a soft-white outline variant and keep any gold detail.

STYLE
Use one simple, geometric outline family with rounded caps and joins. Keep stroke weight, optical size, and internal space consistent. Avoid gradients, shadows, 3D effects, filled circles behind every glyph, tiny internal detail, and mixing unrelated stock icons. Keep icons static by default; if motion is needed, use one brief purposeful reveal and respect reduced-motion settings. Provide an accessible label when an icon conveys meaning; hide it from assistive technology when purely decorative.

WEBSITE AUDIT

Message, deck, and delivery repeat across contact, thanks, and toolkit content; skill-building and team-training are present in the files but not referenced. Navigation uses CSS-drawn menu bars, FAQ uses plus/minus characters, and several lists use CSS bullets/checks rather than a shared icon set.
